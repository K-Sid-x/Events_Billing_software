# 🎪 Ledger.Events - Tent House & Event Management ERP

A simple, fully offline desktop app for **Event Planners, Tent Houses, and Equipment Rental Businesses**.

Unlike regular shop software, this is built for rentals. When you bill a customer, the **stock remains as it is** (it does not decrease permanently because items come back after the event).

## ✨ Key Features
* 📦 **Stock Tab:** Your stock remains as it is. Track chairs, tents, and equipment that go out for an event and return to your warehouse.
* 📑 **Catalog Tab for Billing:** A built-in Catalog tab makes it super easy to select items and add them straight to the customer's bill.
* 👷 **Labour & Wage Tracking:** Easily track daily wage workers (Hajira), advances, and final payments.
* 🧾 **GST Billing:** Create standard bills and GST-compliant PDF invoices instantly.
* 🔐 **Admin Security:** Lock old records so staff cannot edit or delete past bills without an Admin password.
* 🖨️ **Print Studio:** Print professional PDF bills, payment receipts, and even labor ID cards.
